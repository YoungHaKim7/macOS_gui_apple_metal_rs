# The default system font on modern macOS is San Francisco  
The default system font on modern macOS is San Francisco (SF Pro for general UI text and SF Mono for monospaced environments like code and terminals).
- https://developer.apple.com/fonts/

- `Microsoft Sans Serif`

## Key Default Fonts on macOS

- • SF Pro (SF Pro Text / SF Pro Display): The primary sans-serif UI typeface across macOS, supporting variable optical sizes and multiple weights.
- • SF Mono: The default monospaced font for coding, logs, and terminal/console interfaces.
- • New York: Apple's serif typeface used in editorial and reading contexts (such as Apple Books).

# 한글 쓸때 이거 쓰자
- • `Apple SD Gothic Neo`: The built-in Korean sans-serif system font used alongside San Francisco for Hangul text.

## Historical Shifts & Font Location

- • Earlier macOS versions: Before San Francisco became the standard starting with OS X El Capitan, macOS used Helvetica Neue (Yosemite) and Lucida Grande (earlier releases).
- • System font path: Built-in system fonts live in /System/Library/Fonts, and you can manage or reset them using the Font Book app.

# 최신 macOS의 기본 시스템 글꼴은 샌프란시스코(SF Pro)로, 일반 UI 텍스트에 사용되며, 코드나 터미널 같은 고정폭 환경에서는 SF Mono가 사용됩니다.

## macOS의 기본 폰트 키

- • SF 프로(SF 프로 텍스트 / SF 프로 디스플레이): macOS 전반에서 주로 사용되는 산세리프 UI 서체로, 가변 광학 크기와 다양한 굵기를 지원합니다.
- • SF 단색: 코딩, 로그, 터미널/콘솔 인터페이스의 기본 고정폭 글꼴입니다.
- • 뉴욕: 애플 북스와 같은 편집 및 독서용 환경에서 사용되는 애플의 세리프 서체입니다.
- • 애플 SD 고딕 네오: 한글 텍스트에 샌프란시스코와 함께 사용되는 내장 한국어 산세리프 시스템 글꼴입니다.

## 역사적 변화와 글꼴 위치

- • 이전 macOS 버전: 샌프란시스코가 OS X 엘 캐피탄부터 표준이 되기 전까지, macOS는 헬베티카 노이에(요세미티)와 루시다 그란데(이전 버전)를 사용했습니다.
- • 시스템 글꼴 경로: 내장 시스템 글꼴은 /System/Library/Fonts에 위치하며, 폰트 북 앱을 통해 관리하거나 재설정할 수 있습니다.
